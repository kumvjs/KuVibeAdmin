# 系统字典实施计划

时间：2026-09-30（Asia/Shanghai）。需求标识：system-dictionary-20260930。

## 需求与决策

- 用户已确认统一树节点：任意节点可有名称、全局唯一编码、可选字符串值及任意层级子节点。
- 管理员新增、编辑、移动、启停、删除节点；系统管理新增独立字典页面，保留 Vben 上游布局与组件。
- 按任意节点 ID 或稳定编码获取全部下级，支持树形/扁平输出、可选包含自身；不设业务层级上限。
- `fullPathId` 采用 `/1/2/3/`，`fullPathName` 采用 `根 / 子 / 当前`，均包括自身；同时提供 `pathIds`、`pathNames`、从 1 开始的 `depth`。
- 数据库只保存邻接父关系，PostgreSQL recursive CTE 从选定节点向上计算根路径，再向下查询子树。改名和移动立即反映到后代，不接受客户端写入路径。
- 全局编码唯一、同级名称唯一；仅删除无有效子节点的节点，软删除；停用祖先使后代业务可用状态失效，管理页仍显示。有效过滤裁剪整条停用分支。
- 事务级 advisory lock 串行化本模块写入，随后在 READ COMMITTED 新快照中校验祖先链，防并发循环和删除/新增竞态。仅修改字典领域，不改变既有权限模型。
- 读性能：一级节点完整无限级子树整体缓存到 Redis（`sys:dict:{tenant}:tree:{一级节点 ID}:{版本号}`），
  读接口复用同一份缓存并按 `pathIds` 在内存裁剪；写操作提交后按受影响一级节点递增版本号并清理改名/移动的路径索引。
  路径解析（祖先链）始终以数据库为准、不做缓存。实现细节见 implemented/20261002-0830-feature-dict-tree-cache.md。

## 分析与边界

复杂度 Level 2：后端、数据库、前端、初始化菜单和文档。所有新增接口沿用认证、权限和响应封装，bigint ID 全程字符串。仅单租户，tenant_id 预留字段沿用现有约定，不引入租户隔离。

邻接表避免物化名称路径的级联重写；父级索引支持定点查询，路径数组用于循环保护与无歧义消费。前后端自有遍历使用迭代方式；极大结果集仍受数据库/浏览器资源约束，扁平输出适合深树。

Vben 扩展：新增 playground/src/views/system/dict 与 api/system/dict.ts；仅在应用 system 路由添加业务入口。无需修改共享 packages/internal/apps/_core/登录/布局/构建基础文件。

保留开始时全部充值、Docker、锁文件等用户现有改动；不执行用户数据库迁移或发布。

## 计划与验收

1. 后端实体、DTO、CRUD、定点子树查询、权限、初始化种子。
2. 使用 Atlas 项目 Skill：在新建隔离 PostgreSQL 18.6 数据库重放迁移基线后生成迁移，审查 up/down、带数据往返、结构 diff；未安装 Atlas 时如实记录。
3. 独立字典页面：任意层级新增下级，树展示与子树查看，搜索、父级选择、路径展示、权限按钮和错误状态。
4. 聚焦 DTO/路径/深树/鉴权测试，PostgreSQL 并发移动、重复写入、软删除及启停过滤集成测试；类型检查、构建和必要浏览器验收。
5. 更新当前文档与 OpenAPI，审查差异，合并 implemented 笔记。

验收：根/中间/叶子定点查询；兄弟排序；超过常规固定级数；大 ID；改名/移动更新全后代路径；路径不可伪造；循环/孤儿/重复/非法输入被拒；同时互移最多一项成功且树保持无环；祖先停用过滤；父节点带子节点不能删除；初始化可重复且不授权普通用户；旧数据迁移往返不变、有字典数据拒绝回滚。
